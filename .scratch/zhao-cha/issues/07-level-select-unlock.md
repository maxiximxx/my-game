# 07: 选关页与线性解锁

**What to build:** 选关页显示第 1 至 5 关。第 1 关默认开放，未解锁的关卡显示为锁定且不能进入。通关第 n 关后，第 n+1 关解锁。已解锁的关卡可以随时重玩。解锁状态暂存在内存中，刷新页面后会丢失，持久化在第 10 项完成。

**Blocked by:** 02 单关可玩：命中、通关与用时

- [ ] 锁定的关卡不能进入
- [ ] 通关第 n 关后，第 n+1 关变为可进入
- [ ] 已解锁的关卡可以再次进入
