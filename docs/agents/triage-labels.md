# Triage 标签

技能使用五个标准的 triage 角色来描述 issue 的状态。本文件将这些角色映射到本仓库 issue 追踪中实际使用的标签字符串。

| mattpocock/skills 中的标签 | 本仓库使用的标签     | 含义                                     |
| -------------------------- | -------------------- | ---------------------------------------- |
| `needs-triage`             | `needs-triage`       | 维护者需要评估这个 issue                 |
| `needs-info`               | `needs-info`         | 等待报告者提供更多信息                   |
| `ready-for-agent`          | `ready-for-agent`    | 需求已完整说明，可交给无人值守（AFK）的 AI agent |
| `ready-for-human`          | `ready-for-human`    | 需要人工实现                             |
| `wontfix`                  | `wontfix`            | 不会处理                                 |

当技能提到某个角色时（例如"应用 AFK 就绪的 triage 标签"），请使用此表中对应的标签字符串。

如果你们实际使用其他词汇，请修改"本仓库使用的标签"这一列。
